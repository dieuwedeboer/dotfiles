# Agent instructions

Shared instructions for every coding agent on this machine. This file is the
single source of truth: `~/.claude/CLAUDE.md` and `~/.config/opencode/AGENTS.md`
are both symlinks to it, and it lives in the dotfiles repo at `.agents/AGENTS.md`.

Reusable skills live alongside it in `~/.agents/skills/`.
