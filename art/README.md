# Art

Beauty matters.

## Screensaver

Copy custom ASCII art into omarchy's branding directory:

  cp art/monarchy.txt ~/.config/omarchy/branding/screensaver.txt

## Update banner

`monarchy-banner.txt` opens `monarchy-update`. It is 80 columns so it fits the
floating terminal the Omarchy update widget opens; `monarchy.txt` is 100 and
wraps there.
